## 발견·수정한 오류 (자동 수정 완료)

### 문서/정합성 (정적 검토)
1. **MySQL 예약어 충돌** — `year`, `rank` 컬럼 → `stu_year`, `prof_rank`로 개명.
2. **샘플 이메일 오타** — 학생8 `:isj@` → `isj@` 수정.
3. **문서-SQL 인덱스 불일치** — 02 문서의 인덱스 표를 실제 생성/자동생성 구분에 맞게 정정.
4. **성능 실험 대상 부적합** — FK 자동 인덱스가 있는 컬럼 대신 `sname`/`lname`을 실험 대상으로
   선정하여 전/후 비교가 유효하도록 조정(보고서 §8.4와 SQL PART 5 일치화).

### 실서버 실행 중 발견 (MySQL 8.0.45 end-to-end 검증)
5. **CHECK 제약 위반** — 롤백 예제의 `score+50`이 142가 되어 CHECK(0~100) 위반 →
   범위 내 값(`10.00`)으로 수정.
6. **TEMPORARY 테이블 재참조(ERROR 1137)** — digits 임시테이블 5중 self-join 불가 →
   일반 테이블 `gen_digits`로 변경(끝에서 DROP).
7. **트랜잭션/대용량 재실행 안전성** — `'2026-2'` 정리 구문, 상단 cleanup, FK CASCADE,
   base 변수 매핑으로 반복 실행 보장.
