## 7. 인덱스 성능 비교 (EXPLAIN, Q1: WHERE sname='학생05000')

### BEFORE (인덱스 없음)
```
id select_type table   type possible_keys key  rows  Extra
1  SIMPLE      Student  ALL  NULL          NULL 9858  Using where      ← 풀 테이블 스캔
```

### AFTER (idx_student_name 생성 후)
```
id select_type table   type possible_keys     key              rows Extra
1  SIMPLE      Student  ref  idx_student_name  idx_student_name 1    NULL  ← 인덱스 탐색
```

### EXPLAIN ANALYZE 실측 (Q1)
```
BEFORE: Table scan on Student (cost=994 rows=9858) (actual time=0.07..2.17 rows=10012)
        Filter (actual time=1.21..2.72 rows=1)            → 약 2.72 ms
AFTER : Index lookup using idx_student_name (cost=0.35 rows=1)
        (actual time=0.0101..0.0109 rows=1)               → 약 0.011 ms
```

→ **type ALL → ref**, 검사행 9858 → 1, 실행시간 **약 2.72ms → 0.011ms (약 247배 향상)**,
추정비용 **994 → 0.35**.
