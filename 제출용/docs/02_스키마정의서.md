# 02. 스키마정의서 (Schema Definition)

**프로젝트:** 전남대학교 수강신청·성적관리 데이터베이스
**작성일:** 2026-05-31
**DBMS:** MySQL 8.0 / InnoDB / 문자셋 utf8mb4

---

## 1. 개요

본 문서는 `01_요구사항지시서.md`에서 도출한 개념 모델(ER 모델)을 **논리적 모델(관계 스키마)** 로
변환한 결과를 정의한다. 데이터베이스명은 `bokyung`이며, 모든 테이블은 InnoDB 엔진을
사용하여 **참조 무결성(외래키 제약)** 과 **트랜잭션**을 지원한다.

ERD에 대한 시각적 설명은 `erd_description.md`를 참조한다.

---

## 2. 논리적 데이터 모델 (관계 스키마)

밑줄 = 기본키(PK), 이탤릭(*) = 외래키(FK).

```
Dept(deptid, dname, college, office, tel)

Professor(pid, pname, prof_rank, email, office, *deptid)
        FK: deptid → Dept(deptid)

Student(stuid, sname, stu_year, phone, email, *deptid, *advisor_pid)
        FK: deptid → Dept(deptid)
        FK: advisor_pid → Professor(pid)

Lecture(lid, lname, lnum, credit, semester, *pid)
        FK: pid → Professor(pid)

Enrollment(enrollid, *stuid, *lid, enroll_date, status, semester, enroll_type)
        FK: stuid → Student(stuid)
        FK: lid → Lecture(lid)
        UNIQUE(stuid, lid, semester)

Grade(gradeid, *enrollid, score, grade_letter, evaluation_date, remark)
        FK: enrollid → Enrollment(enrollid)
        UNIQUE(enrollid)
```

## 3. 테이블 상세 정의

### 3.1 Dept (학과)

| 컬럼 | 데이터 타입 | 제약 | 설명 |
| --- | --- | --- | --- |
| deptid | INT | PK, AUTO_INCREMENT | 학과번호 |
| dname | VARCHAR(50) | NOT NULL, UNIQUE | 학과명 |
| college | VARCHAR(50) | NOT NULL | 단과대학 |
| office | VARCHAR(50) | NULL | 학과 사무실 |
| tel | VARCHAR(20) | NULL | 학과 전화 |

### 3.2 Professor (교수)

| 컬럼 | 데이터 타입 | 제약 | 설명 |
| --- | --- | --- | --- |
| pid | INT | PK, AUTO_INCREMENT | 교번 |
| pname | VARCHAR(30) | NOT NULL | 이름 |
| prof_rank | VARCHAR(20) | NOT NULL | 직급(전임강사/조교수/부교수/정교수) |
| email | VARCHAR(100) | NULL, UNIQUE | 이메일 |
| office | VARCHAR(50) | NULL | 연구실 |
| deptid | INT | FK→Dept, NOT NULL | 소속 학과 |

### 3.3 Student (학생)

| 컬럼 | 데이터 타입 | 제약 | 설명 |
| --- | --- | --- | --- |
| stuid | INT | PK, AUTO_INCREMENT | 학번 |
| sname | VARCHAR(30) | NOT NULL | 이름 |
| stu_year | TINYINT | NOT NULL, CHECK(1~4) | 학년 |
| phone | VARCHAR(20) | NULL | 연락처 |
| email | VARCHAR(100) | NULL, UNIQUE | 이메일 |
| deptid | INT | FK→Dept, NOT NULL | 소속 학과 |
| advisor_pid | INT | FK→Professor, NULL | 지도교수(미배정 허용) |

### 3.4 Lecture (강의)

| 컬럼 | 데이터 타입 | 제약 | 설명 |
| --- | --- | --- | --- |
| lid | INT | PK, AUTO_INCREMENT | 강의번호 |
| lname | VARCHAR(60) | NOT NULL | 강의명 |
| lnum | VARCHAR(20) | NOT NULL | 학수번호/분반 |
| credit | TINYINT | NOT NULL, CHECK(1~3) | 학점 |
| semester | VARCHAR(10) | NOT NULL | 개설 학기(예: 2026-1) |
| pid | INT | FK→Professor, NOT NULL | 담당 교수 |

### 3.5 Enrollment (수강신청) — 약 개체

| 컬럼 | 데이터 타입 | 제약 | 설명 |
| --- | --- | --- | --- |
| enrollid | INT | PK, AUTO_INCREMENT | 수강신청 ID(대리키) |
| stuid | INT | FK→Student, NOT NULL | 신청 학생 |
| lid | INT | FK→Lecture, NOT NULL | 신청 강의 |
| enroll_date | DATE | NOT NULL, DEFAULT(CURRENT_DATE) | 신청일 |
| status | ENUM('수강중','취소','완료') | NOT NULL, DEFAULT '수강중' | 수강 상태 |
| semester | VARCHAR(10) | NOT NULL | 수강 학기 |
| enroll_type | ENUM('정규','재수강') | NOT NULL, DEFAULT '정규' | 신청 구분 |
| | | **UNIQUE(stuid, lid, semester)** | 동일 학기 중복 신청 방지 |

### 3.6 Grade (성적) — 약 개체

| 컬럼 | 데이터 타입 | 제약 | 설명 |
| --- | --- | --- | --- |
| gradeid | INT | PK, AUTO_INCREMENT | 성적 ID(대리키) |
| enrollid | INT | FK→Enrollment, NOT NULL, UNIQUE | 대상 수강신청(1:1) |
| score | DECIMAL(5,2) | NOT NULL, CHECK(0~100) | 점수 |
| grade_letter | VARCHAR(2) | NULL | 등급(A+, A0, ...) |
| evaluation_date | DATE | NULL | 평가일 |
| remark | VARCHAR(100) | NULL | 비고 |

## 4. 외래키(FK) 매핑 정의

| FK 이름 | 자식 테이블.컬럼 | 부모 테이블.컬럼 | ON DELETE | ON UPDATE | 의미 |
| --- | --- | --- | --- | --- | --- |
| fk_prof_dept | Professor.deptid | Dept.deptid | RESTRICT | CASCADE | 교수 소속 학과 |
| fk_stu_dept | Student.deptid | Dept.deptid | RESTRICT | CASCADE | 학생 소속 학과 |
| fk_stu_advisor | Student.advisor_pid | Professor.pid | SET NULL | CASCADE | 지도교수 |
| fk_lec_prof | Lecture.pid | Professor.pid | RESTRICT | CASCADE | 강의 담당 교수 |
| fk_enr_stu | Enrollment.stuid | Student.stuid | CASCADE | CASCADE | 수강신청 학생 |
| fk_enr_lec | Enrollment.lid | Lecture.lid | CASCADE | CASCADE | 수강신청 강의 |
| fk_grade_enr | Grade.enrollid | Enrollment.enrollid | CASCADE | CASCADE | 성적-수강신청 |

### 4.1 삭제 규칙(ON DELETE) 설계 근거
- **RESTRICT** (Dept, Professor 참조): 소속 학생/교수/강의가 남아 있는 학과·교수는 삭제를 막아
  마스터 데이터의 무결성을 보호한다.
- **SET NULL** (지도교수): 교수가 삭제되면 지도 학생의 `advisor_pid`를 NULL로 만들어
  학생 데이터 자체는 보존한다(부분 참여이므로 가능).
- **CASCADE** (Enrollment, Grade): 학생·강의가 삭제되면 종속된 수강신청과 성적도 함께 삭제하여
  약 개체의 존재 의존성을 구현한다.

## 5. 관계 매핑 정의 (Relationship Mapping)

| 관계 | 카디널리티 | 구현 방법 | 관련 제약 |
| --- | --- | --- | --- |
| Student–Dept | N:1 | Student.deptid FK | NOT NULL (전체 참여) |
| Professor–Dept | N:1 | Professor.deptid FK | NOT NULL (전체 참여) |
| Professor–Student(지도) | 1:N | Student.advisor_pid FK | NULL 허용 (부분 참여) |
| Professor–Lecture | 1:N | Lecture.pid FK | NOT NULL (전체 참여) |
| Student–Lecture | M:N | Enrollment 교차 테이블 | 양 FK NOT NULL + UNIQUE(stuid,lid,semester) |
| Enrollment–Grade | 1:1 | Grade.enrollid FK | UNIQUE(enrollid) |

---

## 6. 인덱스 설계 (요약)

성능 최적화를 위해 다음 인덱스를 정의한다. 상세 실험은 `optimization.sql` 및
`03_개발완료보고서.md`의 성능 최적화 절을 참조한다.

| 인덱스 | 대상 | 생성 방식 | 목적 |
| --- | --- | --- | --- |
| (PRIMARY) | 각 테이블 PK | PK 자동 생성 | 기본 키 조회 |
| **idx_student_name** | Student(sname) | `optimization.sql`에서 명시 생성 | 이름 기반 학생 검색 가속 |
| **idx_lecture_name** | Lecture(lname) | `optimization.sql`에서 명시 생성 | 강의명 기반 검색 가속 |
| idx_grade_score | Grade(score) | `optimization.sql`에서 명시 생성 | 점수 범위 검색 가속 |
| (FK 자동 인덱스) | Enrollment(stuid), Enrollment(lid) | InnoDB가 FK에 자동 생성 | 학생/강의별 조인·조회 |
| uq_enroll | Enrollment(stuid,lid,semester) | UNIQUE 제약 자동 인덱스 | 중복 신청 방지 + 복합 조회 |
| uq_grade_enroll | Grade(enrollid) | UNIQUE 제약 자동 인덱스 | 1:1 조인 가속 |

> 참고: InnoDB는 외래키 컬럼에 대해 **자동으로 보조 인덱스**를 생성하므로
> `Enrollment.stuid`/`Enrollment.lid`는 별도 인덱스를 만들지 않아도 조인 시 인덱스를 사용한다.
> 따라서 성능 실험(`optimization.sql` PART 5)은 자동 인덱스가 없는 `sname`·`lname`을 대상으로 한다.

## 7. 무결성 제약 요약

| 무결성 유형 | 구현 |
| --- | --- |
| 개체 무결성 (Entity Integrity) | 모든 테이블 PK NOT NULL + 유일 |
| 참조 무결성 (Referential Integrity) | 7개 FK 제약 + ON DELETE/UPDATE 규칙 |
| 도메인 무결성 (Domain Integrity) | ENUM, CHECK(점수·학년·학점 범위) |
| 키 무결성 (Key Integrity) | UNIQUE(dname, email, (stuid,lid,semester), enrollid) |
